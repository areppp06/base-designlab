# BASE DESIGN LAB

Interior design website for **BASE DESIGN LAB (Malaysia)**.

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- Cloudflare Workers static assets (`wrangler`)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run deploy
```
